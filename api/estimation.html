popo.estimation#

Conversion to pandapower and weighted-least-squares state estimation. Needs the estimation extra. See State estimation.

Converting a feeder

to_pandapower

Convert an OpenDSS circuit and locate the busbar the study measures.

check_conversion

Solve the converted network and the circuit it came from, and compare every bus.

set_loading

Set every load's demand for one time step.

true_state

Solve the power flow and return the state an estimator has to recover.

Estimating

observability

Count the equations a measurement set gives the estimator against those it needs.

Observability

Whether a measurement set has enough equations to determine the state.

estimate_voltages

Estimate every bus voltage from a substation measurement and some meters.

MeasurementNoise

Standard deviations of the measurements an estimator is given.

voltage_error

Summarise how far an estimate sits from the true state.

zero_injection_buses

Buses whose injection is known to be zero, and so constrain the solve.

Forecasts as inputs

run_comparison

Compare state estimation from coherent versus incoherent substation input.

ComparisonResult

Outcome of comparing coherent and incoherent substation measurements.
