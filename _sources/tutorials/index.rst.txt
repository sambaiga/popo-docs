Tutorials
=========

Three notebooks that each work through a complete study. They run when the documentation is built, so
every number and figure in them comes from the current code. The feeders and profiles they use are in
the repository's test data (``tests/data``); to run a notebook yourself, clone the repository (see
:doc:`../getting-started/installation`) and open it from the ``notebooks`` directory.
