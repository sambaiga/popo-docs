# API reference

The reference lists every public class and function in popo, one page per subpackage. Each name links to
a page with its full signature, parameters and return values. For explanations and examples, see the
[user guide](../guide/index.md).

| Subpackage | Contents |
|---|---|
| [`popo.network`](network.md) | Circuits as defined: elements, customers and feeder screening. |
| [`popo.powerflow`](powerflow.md) | Results of a solved circuit, time-series solves and penetration sweeps. Needs the `opendss` extra. |
| [`popo.scenarios`](scenarios.md) | Household demand, rooftop solar, EV charging, storage and inverter control. Needs the `opendss` extra. |
| [`popo.standards`](standards.md) | Statutory voltage limits and inverter characteristics. Needs no solver. |
| [`popo.estimation`](estimation.md) | Conversion to pandapower and weighted-least-squares state estimation. Needs the `estimation` extra. |
| [`popo.profiles`](profiles.md) | Loading and synthesising half-hourly demand, PV and EV profiles. |
| [`popo.plotting`](plotting.md) | Network diagrams, figure style, line plots and tables. Needs the `plot` extra. |
