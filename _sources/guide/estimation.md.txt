# State estimation

{py:mod}`popo.estimation` estimates every bus voltage of a feeder from the few measurements that exist,
using pandapower's weighted-least-squares estimator. It needs the `estimation` extra.

## Convert, then check

```python
net, lv_bus = to_pandapower(Path("feeder/Master.dss"))
check_conversion(net)          # pandapower against OpenDSS, bus by bus
```

{py:func}`~popo.estimation.to_pandapower` restores each transformer's nameplate turns ratio, which the
converter would otherwise replace with the ratio of its buses' voltage bases.
{py:func}`~popo.estimation.check_conversion` solves both engines at the same loading so the model is checked
before it is trusted. The difference that remains is the cost of a balanced model of an unbalanced feeder.

## Estimate

```python
voltages, substation_mw, substation_mvar = true_state(net)
observability(net, lv_bus, metered=len(metered))          # enough equations at all?
estimate = estimate_voltages(
    net, lv_bus, voltages[lv_bus], substation_mw, substation_mvar,
    meter_mw, meter_mvar, metered=metered, line_flows=sensors,
)
voltage_error(estimate, voltages)
```

The substation is metered on its transformer; each metered customer enters as a pseudo-measurement of its
demand with a 10 % uncertainty; line power-flow sensors can stand in for missing meters where they separate
an unmetered customer from the rest. {py:func}`~popo.estimation.estimate_voltages` returns `None` when no
estimate exists, which is a result rather than an error.

## Forecasts as inputs

{py:func}`~popo.estimation.run_comparison` asks whether the kind of substation forecast matters: a coherent
forecast, whose active power, reactive power and voltage describe a state the network can be in, against
three separately calibrated forecasts of the same accuracy.
