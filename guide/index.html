User guide#

The user guide explains each part of popo with examples that run when the documentation is built, so every table and figure on these pages is real output. Each page ends with the limitations you should know before relying on its results.

The pages follow the order of a study: load a network, simulate it, add customer technologies, check the result against a standard, and estimate the state of a network that is only partly measured.

The example feeder#

The examples use a real low-voltage feeder from the UK: one 500 kVA, 11/0.416 kV transformer supplying 188 single-phase customers over 378 lines. It is part of the repository’s test data in tests/data, which is not included in the installed package. To run the examples, clone the repository (see Installation) and run them from its root directory.
